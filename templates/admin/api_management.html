Multi-Provider Fallback Logic & Operational Integrity

Sequential Fallback

EduMate dispatches study requests to the highest priority enabled provider. If an upstream provider returns a quota limit (429), gateway timeout (504), or network error, EduMate automatically falls back to the next enabled provider without losing the student's study request.

Quota & Cost Conservation

Providers are executed sequentially, never in parallel waste. If your primary provider succeeds on its first attempt, no downstream requests are made, protecting your API limits and compute usage.

Zero Key Exposure

Raw API credentials never leave the server. Keys are masked during display, excluded from API JSON responses, and sanitized from server audit logs and exception traces.
